# BetterX

A free gear-comparison addon for World of Warcraft: Forever.

## Download

**[Download the latest update](https://github.com/bakerbiz420-collab/BetterX/releases/latest)**

Open **Assets** and download the file named **BetterX-VERSION.zip**.
The automatically generated “Source code” downloads are not the addon installer.

## Install or update

1. Exit World of Warcraft completely.
2. Extract the release ZIP.
3. Copy the **BetterX** folder into your game’s `_forever_/Interface/AddOns/` folder.
4. Replace existing files when prompted. The final location should be
   `_forever_/Interface/AddOns/BetterX/BetterX.toc`.
5. Restart the game and enable **Better X** in the AddOns list.

Your saved preferences are preserved. Leave the game’s WTF folder alone.

## Testing

Current build: **0.3.34**. Includes 28 profile routes, support roles, pets and
supported proc effects. The consolidated offline review passed 41,908 checks;
focused live gameplay acceptance remains in progress.

Open BX to check your selected profile and comparison goal. Optional details
are controlled through the existing menu.

selected BX profile/goal and a screenshot showing both compared items.

stated limits; they are not exact DPS/HPS measurements or universal BiS labels.
